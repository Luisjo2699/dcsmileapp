# Dental Clinic Management System (DCSmileApp)

## Description
This project resolves the need to digitize and optimize the administration of a medium-sized dental clinic. The system centralizes patient record management, clinical history tracking, and detailed treatment logging through an interactive odontogram, eliminating paper-based processes and facilitating a direct communication channel between patients and healthcare professionals.

## Technologies
* **Frontend:** HTML5 and CSS3 for structure, responsive design, and modern visual styles.
* **Logic:** JavaScript (Vanilla ES6+) for system logic, DOM manipulation, and event handling.
* **Icons:** Font Awesome for incorporating institutional and interface iconography.
* **Storage:** LocalStorage API for local data storage and persistence of system data (users, patients, histories, and messages).

## Installation and Usage
1. Clone this repository to your computer:
   ```bash
   git clone [https://github.com/Luisjo2699/dcsmileapp.git](https://github.com/Luisjo2699/dcsmileapp.git)

2. Open the project folder in your preferred code editor (such as VS Code).

3. Open the index.html file directly in your web browser (or use an extension like Live Server in VS Code for a better local execution experience).

4. Explore the public module or log in to the professional panel with the system credentials to manage patients and test the interactive odontogram.
